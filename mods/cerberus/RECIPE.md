# cerberus controller

A resident zero-height block in cockpit receives cerberus.toggle/close. A mod.open copy forwards to it and closes itself. Poll each machine's local herdr-hud panes every three seconds, qualify remote addresses without truncating machine prefixes, exclude workers, and publish ordered Head metadata. Never infer workers from tab names. Retain stale snapshots and pause broadcasts when any helper is unavailable.

Open a named, frameless window at 96% width and 92% height with a 44 px cerberus-bar above the grid. Keep its returned id. Debounce structural and blocked-border changes for one second while open; ordinary status changes update headers in place. Wait for broadcasts before rebuilding or closing on request. Closing the controller closes its window. Model helpers are copied byte-for-byte into cerberus-bar because Herdr isolates mod imports; tests enforce equality.

Verify with synthetic app state and helper responses. Live installation, geometry, command delivery to the zero-height block, and PTY input need an authorized interactive check.
