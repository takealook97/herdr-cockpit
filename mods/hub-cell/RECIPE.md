# hub cell header

A one-line 26 px header above an existing terminal block: a live status dot, 12 px semibold tab name, dim space name, and right-side focus icon. Blocked status adds a theme blocked border. Clicking the name requests space-tree.hub-close, then runs space.select and tab.select with complete source ids; clicking expand stores a focus address for a 2:1 layout. Clicking it again restores the grid. Empty grids explain how to start a Head. Use live panes and shared metadata; never open or write terminals from a header.
