# Space tree

A compact machine/space/tab/pane tree with persistent folds, colored section rails, aliases, inline rename, keyboard navigation and guarded tab moves. The Spaces header offers expand/collapse and new-space controls. The first row under This computer is hub: a space-height row with a dedicated rail, Head count and active highlight. It is never duplicated in the regular space list.

Click hub to open a real local space named hub, created lazily and moved to index 1. Ctrl-Shift-H (`space-tree.hub`) toggles between it and the previous space. Hub's tab contains native terminal panes running `hc attach --observe --history 2000 <address>`; input is disabled. Native pane shortcuts and resizing work normally. Expand hub to see observer panes named `<source tab> · <source space>` with source model/effort. Go to the source space to type into an agent.

`hub.js` owns the manager and `hub-model.js` provides pure observer detection, Head selection, command arguments and reconciliation planning. Heads come from per-machine `herdr-hud panes` snapshots, excluding all orch workers, observers and hub's own terminals. Labels identify observers; attach/--observe argv supports older helpers. Full remote addresses stay intact. Every successful poll reconciles hub's first tab: add missing observers, remove observers for absent Heads, and remove the initial shell once a surviving observer exists. No terminal outside the hub tab is touched. User-created shells added later are preserved. In-flight additions are deduplicated; stale helper snapshots pause reconciliation. No layout mutation or separate hub mod is required.

`plumbing.js` retains Git/worktree order, machine refresh/reconnect and menus. `model.js` projects the tree, `rows.js` renders, `rename.js` owns inline editing and `tree-menu.js` provides alias actions. Up/Down selects a highlight, Left/Right folds, Enter navigates, F2 edits, Enter/blur commits and Escape cancels. Machine and terminal names use shared aliases. Space/tab/pane rows use native navigation. Active orch run tabs cannot be moved. Every minute, dead folds and aliases are pruned while offline machine state is retained.

Tests use synthetic terminal metadata and a fake command host; they never create real spaces or terminals. Run `node --test mods/space-tree/*.test.mjs` and `herdr-app check "$PWD/mods/space-tree"`. Live creation, observer read-only behavior, native shortcuts and remote reconnects still need an authorized interactive check. Generated editor files and test fixtures are excluded from installation.
